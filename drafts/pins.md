# Pinned repository descriptions (proposals)

- VMAFx/vmafx: Fork of Netflix/vmaf: perceptual video quality (VMAF) with CUDA, SYCL, HIP and Metal backends, each checked against the CPU scores.
- golusoris/golusoris: Composable Go framework: opt-in fx modules for config, logging, database, HTTP, OpenTelemetry, jobs, cache, auth and Kubernetes.
- golusoris/goenvoy: Go client libraries for media automation, metadata and download APIs, as zero-dependency modules.
- cordanaLLM/praetor: Governance engine for repository fleets: one AGENTS.md per repository, compiled into the instruction files of six coding clients.
- VMAFx/ffmpeg-patches: One shared series of FFmpeg fixes in git format-patch form, applied onto one pinned FFmpeg release; every fix is sent upstream.
- lusoris/SnatchArr: Finds missing media across *arr instances while respecting hourly caps.
